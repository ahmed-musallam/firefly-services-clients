# Changelog

All notable changes to this project will be documented in this file.

## [1.0.0] - 2025-11-20

### Added

- Initial release of storage-and-collaboration-client
- Support for Projects APIs (create, get, list, discard, permissions)
- Support for Folders APIs (create, get, list children, permissions)
- Support for Files APIs (get, download, upload, image renditions, permissions)
- Support for Jobs APIs (status monitoring)
- Job polling utilities for async operations
- TypeScript types generated from OpenAPI spec
