# Changelog

All notable changes to this project will be documented in this file.

## [1.0.0] - 2025-12-09

### Added

- Initial release of lightroom-client
- Support for Lightroom Presets API
- Support for XMP settings application
- Support for Auto-straighten
- Support for Auto-tone adjustments
- Support for Manual image edits
- Job polling utilities for async operations
- TypeScript types generated from OpenAPI spec
